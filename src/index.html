Azure Web Lab

This static site was deployed to Azure App Service using infrastructure-as-code and GitHub Actions.

What was built

  • Resource group rg-web-lab in East US
  • App Service plan (Free F1) + App Service app-web-lab-zo8pma
  • Terraform configuration that creates the above resources
  • GitHub Actions workflow that deploys the src/ folder on every push to main
  • Service principal + GitHub secret for secure Azure login

How updates work

Edit files in src/, commit, and push to main. The workflow automatically redeploys the site.
